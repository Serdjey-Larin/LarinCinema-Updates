# LARIN CINEMA — официальные обновления Android TV

Публичный репозиторий предназначен **только для распространения APK и заметок к релизам** приложения LARIN CINEMA.

Исходный код приложения находится в отдельном закрытом репозитории и здесь не публикуется.

## Как приложение находит обновления

LARIN CINEMA проверяет публичный GitHub Releases API этого репозитория. Формат релиза:

- тег: `larin-cinema-X.Y.Z-test`
- имя APK: `LarinCinema-X.Y.Z.apk`

Например, для версии 1.0.9:

- Release tag: `larin-cinema-1.0.9-test`
- Asset: `LarinCinema-1.0.9.apk`

APK должен быть прикреплён именно к GitHub Release. Простая загрузка APK в корень репозитория не публикует обновление для приложения.

## Установка

1. На Xiaomi / Android TV откройте LARIN CINEMA.
2. Выберите **↻ Обновления**.
3. Если найдена новая версия, выберите **Скачать обновление**.
4. Подтвердите системную установку Android.

Android может запросить разрешение на установку неизвестных приложений. Установка выполняется только после подтверждения пользователя.

## Важные сведения

- Загружайте APK только из релизов этого репозитория.
- Для обновления поверх установленной версии APK должен иметь ту же подпись, что и установленное приложение.
- Не удаляйте и не меняйте ключ подписи релизов. Храните резервную копию keystore в безопасном месте.
- Если APK подписан другим ключом, Android не сможет обновить приложение поверх установленного.
- Не публикуйте здесь исходники, пароли, keystore или токены доступа.

## Релизы

Пока релизы не опубликованы. Первый APK появится после настройки безопасной подписи и автоматической публикации из закрытого репозитория разработки.
